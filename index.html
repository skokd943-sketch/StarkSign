Apple ID

⚠️ Внимание: приложения с бесплатным Apple ID не ставятся из Safari. Установка работает только способом AltStore / SideStore — подпиши здесь, а поставь через них.

Введи Apple ID и пароль. Если Apple запросит двухфакторный код, введи его здесь. Пароль не сохраняется в браузере.

AltStore .p12

Подпись без входа в Apple ID. Выбери экспортированный из AltStore сертификат .p12, его пароль и совместимый профиль .mobileprovision.

Source для установки

Для бесплатного Apple ID: подключи каталог Stark Sign как Source — приложение подпишет и поставит SideStore или AltStore.
